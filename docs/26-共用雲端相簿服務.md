# 26. 共用雲端相簿服務（GAS + 網站）

> 透過 **Google Apps Script (GAS)** 讀取 **共用雲端硬碟（Google Workspace）** 的目錄與相片，在網站上產生**相簿列表**與**可分享的相簿連結**，供公開頁面展示扶輪活動相片。相片仍只存於雲端硬碟，網站不佔用額外空間。

---

## 一、目的與範圍

| 項目 | 說明 |
|------|------|
| **用途** | 將共享雲端硬碟內各社上傳的扶輪活動相片，以「相簿」形式展示在公開網站，並提供可分享的 URL。 |
| **資料來源** | 共用雲端硬碟中的資料夾結構（例：年度 / 社名-活動-日期）；不複製、不搬移檔案。 |
| **機制** | GAS 讀取硬碟目錄與檔案，回傳**縮圖 URL**、**原圖／下載 URL** 給網站；網頁僅顯示連結內容，不儲存相片。 |

---

## 二、架構概覽

```
使用者瀏覽網站
    → 網站 (Rails) 請求 GAS 網頁應用程式
    → GAS 讀取共用雲端硬碟（依 Folder ID）
    → 回傳 JSON：相簿列表 或 某相簿內相片（thumbnailLink / webContentLink）
    → 網站渲染相簿列表頁 / 相簿內頁（縮圖網格 + 點擊燈箱看大圖）
```

- **空間**：相片只存在雲端硬碟，網站與 GAS 皆不另存一份。
- **權限**：相簿能否被看見，取決於該資料夾的分享設定（建議：「知道連結的使用者皆可查看」）。

---

## 三、GAS 端：腳本與部署

### 3.1 腳本位置與設定

- **腳本範本**：專案內 `scripts/gas/SharedDriveAlbum.gs`（可複製到 [Google 指令碼編輯器](https://script.google.com/) 使用）。
- **必要設定**：
  - 在 GAS 專案中啟用 **Drive 進階服務**：編輯器 → 擴充功能 → Google 服務 → 啟用 **Drive API**。
  - 在 GAS 專案中設定 **指令碼屬性**：`ROOT_FOLDER_ID` = 共用雲端硬碟的「根資料夾」或要當作相簿根目錄的資料夾 ID（在雲端硬碟中右鍵該資料夾 → 取得連結 → 連結中的 ID）。

### 3.2 部署為網頁應用程式

1. 在指令碼編輯器：**部署** → **新增部署** → 類型選 **網頁應用程式**。
2. **執行身份**：我（您的帳號）。
3. **具有存取權的使用者**：**任何人**（網站需能無需登入即可呼叫）。
4. 部署後取得 **網頁應用程式 URL**（形如 `https://script.google.com/macros/s/xxxxx/exec`）。

### 3.3 GAS 提供的介面（給網站呼叫）

| 參數 | 說明 | 回傳 JSON |
|------|------|------------|
| `action=folders` | 列出 ROOT 下的子資料夾（例：年度 2025-26、2026-27） | `{ "folders": [ { "id", "name", "photo_count" } ] }` |
| `action=folders`&`folder_id=xxx` | 列出指定資料夾下的子資料夾（例：年度下的活動相簿） | `{ "folder_name", "folders": [ { "id", "name", "photo_count" } ] }` |
| `action=photos`&`folder_id=xxx` | 列出指定資料夾內的相片 | `{ "folder_name", "photos": [ { "id", "name", "thumbnail_link", "web_content_link" } ] }` |

網站流程：首頁列出年度 → 點年度列出該年活動相簿 → 點相簿顯示相片（兩層結構）。

網站以 **GET** 請求上述 URL 並帶查詢參數即可。

## 四、網站端（Rails）設定

### 4.1 環境變數

在 `.env`（本機）或 **Cloud Run → 變數與密碼** 設定：

| 變數名稱 | 說明 |
|----------|------|
| `GAS_ALBUM_WEB_APP_URL` | GAS 網頁應用程式 URL（例如 `https://script.google.com/macros/s/xxxxx/exec`）。未設定時，相簿頁會顯示「尚未設定」說明。 |

### 4.2 路由與頁面

| 路徑 | 說明 |
|------|------|
| `GET /albums` | 相簿列表（由 GAS `action=folders` 取得並顯示）。 |
| `GET /albums/:folder_id` | 單一相簿內相片（由 GAS `action=photos&folder_id=:folder_id` 取得）；縮圖網格 + 點擊以燈箱看大圖。 |

相簿列表與相簿內頁皆可**分享連結**至公開網站或社群。

---

## 五、共用雲端硬碟建議結構與權限

- **資料夾結構**：例如一層為「年度」或「社名」，其下為「社名-活動-日期」等子資料夾，每個子資料夾即為一本「相簿」。
- **分享設定**：要讓網站訪客能看到相片，該資料夾（或上層共用硬碟）須設為 **知道連結的使用者皆可查看**；僅限內部時則維持僅組織或特定成員可檢視。

## 六、如何驗證 GAS 取得的資料是否正確

### 6.1 瀏覽器直接打網址（看原始 JSON）

把部署後的 **exec 網址** 貼到瀏覽器，加上參數：

- **根目錄子資料夾**：`{你的GAS網址}?action=folders`  
  → 應看到 `folders` 陣列，名稱應為 2025-26、2026-27、2027-28 等。若不對，代表 ROOT_FOLDER_ID 指錯層。
- **某資料夾下的子資料夾**：`{你的GAS網址}?action=folders&folder_id=資料夾ID`  
  → 可填入 2025-26 的 ID，確認是否列出活動相簿。
- **某資料夾內的相片**：`{你的GAS網址}?action=photos&folder_id=資料夾ID`  
  → 可填入某個活動相簿的 ID，確認是否列出相片。

資料夾 ID 取得方式：雲端硬碟中該資料夾右鍵 → 取得連結 → 網址裡 `folders/` 後面的字串。

### 6.2 在 GAS 編輯器執行測試函式

腳本內有 **`testRootAndFolders()`**。在 [script.google.com](https://script.google.com) 選此函式 → 執行 → 授權後，到 **檢視 → 執行紀錄** 查看：目前 ROOT_FOLDER_ID、以及 listFolders() 回傳的 JSON 與第一層資料夾名稱列表。可據此確認根目錄是否正確。

詳見 `scripts/gas/README.md` 的「如何驗證 GAS 取得的資料是否正確」。

## 八、維運注意

- **GAS 配額**：Apps Script 有每日執行與 URL 擷取次數限制；若相簿很多或流量大，可考慮在網站端做短期快取（例如 5 分鐘）以減少對 GAS 的請求。
- **錯誤處理**：若 GAS 未設定、逾時或回傳錯誤，網站會顯示「無法取得相簿資料」等提示，不影響其他服務。
